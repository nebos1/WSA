# Web server apps
These are exercises completed for the Web Server Applications subject in Uni.


## Web Scripting Applications

JavaScript exercises built with React, Vite and CSS. Each folder is a separate application.

## Exercises

- [EX1](./EX1) — Calculator, array operations and SVG charts.
- [EX2](./EX2) — Class inheritance, football statistics and library queries.
- [EX3](./EX3) — Fetch API, filtering and localStorage record management.
- [EX4](./EX4) — JavaScript modules, password generation and Fetch API.
- [EX5-6](./EX5-6) — React components and task lists.
- [EX7](./EX7) — Shop, basket, routing and a JSON server API.

Each folder contains a short README and the full assignment document(BG language).
